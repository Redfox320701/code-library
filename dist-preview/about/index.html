About this library

A small, free library of 8 carefully written articles about learning to code — built for readers, not for algorithms.

What you'll find here

Every article is short enough to read in one sitting and concrete enough to learn from. Each one is tagged with a topic — Python, web development, JavaScript, AI, computer science, or tools — and a difficulty level, so you can start exactly where you are: Beginner, Intermediate, or Advanced.

The reading experience is deliberately calm: no popups, no ads, no tracking, and a dark mode toggle if you read at night. Articles are hosted as static pages, so they load fast on any connection.

How articles get published

Articles live as Markdown files in a public GitHub repository. When a new article is added, the site rebuilds itself automatically and the new piece appears on the library page within a minute or two — no servers to babysit, nothing to renew.

Reuse and credit

The articles are educational material. You're welcome to read them, share them, and use them in a class or study group. If you spot an error, opening an issue on the repository is the fastest way to flag it.
